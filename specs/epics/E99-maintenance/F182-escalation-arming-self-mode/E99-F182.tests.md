# Escalation arms per front-end — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test,
> and every row names the mutant that kills it. The Reviewer fails the feature if any R-id
> lacks a passing test, or if a named mutant survives.
>
> **Suites.** Behavioral rows for `builder-role.sh`, `init.sh`, the installer summary and the
> docs live in `tests/test_escalation.sh` (existing helpers `mkfix`, `role`, `err`, `rc`,
> `install_to`, `set_models`, `arming_of`, `verdict_for`; new cases are **appended** after the
> E17-F05 block under a `# ══ E99-F182 — per-front-end gate ══` banner, R-ids qualified
> `F182-Rn`). The detector has its own suite, `tests/test_host_frontend.sh`, because it reads
> the ambient environment: every run goes through an `hrun`-style gateway under `env -i`
> with PATH, a sandboxed HOME and only the named variables (copied from
> `tests/test_agents_host.sh`). The self-mode end-to-end row lives in `tests/test_self_mode.sh`.
> The installer-ships-the-tool row lives in `tests/test_install.sh`.
>
> **House constraints.** POSIX `sh`, `set -eu`, `trap … EXIT` + `trap 'exit 1' HUP INT TERM`
> in every suite that uses `mktemp`; `CODEX_HOME` sandboxed on every installer call; no
> `VERSION` literal; no diff of a DO-NOT-TOUCH file against `main` (`cksum` instead); prose
> rows grep the **installed** copy (`$T/<tgt>/.harness/…`) inside a **bounded slice** (the
> `### Which Builder` section, extracted by heading line numbers — the house awk heading
> extractor is fence-blind, so extract with `awk 'f && /^### /{exit} /^### Which Builder/{f=1} f'`
> and keep the fenced call inside the slice); co-occurrence anchors fold newlines
> (`tr '\n' ' ' | tr -s ' ' | grep -qE 'A[^.]{0,N}B'`); every flipped sentence pairs a
> positive anchor with a negative `! grep -qF '<old phrase>'` on the same slice.
>
> **Pre-change RED (Builder obligation).** Confirm each prose anchor RED on the pre-change
> blob (install from a `git stash`-ed tree into a second temp dir, checking the stash
> command's status) before trusting it; record it in `progress/E99-F182/builder.md`.

## Mutation protocol (Builder T13; Reviewer 3b)

One mutant at a time, `cp <file> <file>.mutbak` before, `mv` back after (restore in the
trap, `cksum` compare after each), print the applied diff (non-empty, or the run is void),
under `scratchpad/E99-F182-builder/` (or `-reviewer/`). Re-install into a fresh temp dir
after each prose or installer mutant (those rows read installed copies). Each mutant is a
**whole clause** — a branch, a comparison, a sentence — never a single character.
