## Mechanism

1. **Layout prefix variable.** Command heredocs are `<<'EOF'` (no expansion). Switch
   the reconciled bodies to unquoted `<<EOF` ONLY where a path needs `$HP` would churn
   escaping across ~1200 lines — instead generate into CMDDIR with the `.harness/`
   prefix as today and, in self mode, apply one deterministic transform:
   `sed 's|\.harness/||g'` plus the sdd-pr-loop banner-line swap. R2's reconciliation
   makes the transform total (no prose survives whose meaning breaks when the prefix
   drops); the F02 gate keeps that true.
2. **`--self` flag** parsed with the existing arg loop; sets `SELF_MODE=1`,
   `TARGET="$SRC"`, refuses extra target/`--umbrella`. Runs ONLY: shim emission,
   command generation+transform, arming write. No §1/§2/§7 stages (R6).
3. **Model preservation (R3).** Before regenerating, harvest `model:` from each
   existing `.claude/agents/<role>.md` into `self_model <role>`; in self mode
   `resolve_model claude <role>` returns that harvested value at the top of the
   function — ONE choke point, so `emit_agent`, `models_any` and
   `escalation_verdict` all see it (R4 falls out for free).
4. **Arming (R4).** `write_escalation_arming` parametrized on destination:
   `$H/.escalation-arming` normally, `./.escalation-arming` in self mode.
5. **Regenerate + commit** the 15 files via `--self`; the diff IS the reconciliation
   review surface.
