## Mechanism

`--self` does NOT reimplement or restructure any emitter ("reimplementing a tool
invites a bug per feature"). It runs the REAL `install_one` on a throwaway mktemp
target — the entire existing pipeline through its front door — and transforms that
target's output into the source layout:

1. **Harvest (R3)** — before anything is written, read `model:` from each existing
   `$SRC/.claude/agents/<role>.md` into a role→model table (`self_model_of`).
2. **Temp install** — `SELF_MODE=1`; `install_one "$(mktemp -d)"` with
   `AGENTS_OVERRIDE=claude`, `BUILDER_BACKEND_OVERRIDE=in-session`, and
   `PR_LOOP_OVERRIDE` mirroring the repo's own `pr_loop.enabled` (R5). A guard at the
   top of `resolve_model` returns the harvested value for `claude` roles in self
   mode — ONE choke point, so `emit_agent`, `models_any` and `escalation_verdict`
   (hence `write_escalation_arming`, R4) all see the repo's real tiers.
3. **Layout transform** — every `tmp/.claude/{agents,commands}/*.md` is piped through
   `self_transform` (strip `s|\.harness/||g` FIRST, then swap the stripped
   `sdd-pr-loop` path-resolution line for the source-layout banner — order matters:
   the banner itself names `.harness/`) into `$SRC/.claude/…`; R2's T1/T2
   reconciliation is what makes the strip total. `tmp/.harness/.escalation-arming`
   is copied verbatim to `$SRC/.escalation-arming` (or reclaimed when absent).
   Gate-off removal mirrors install_one: the two pr-loop names are removed from
   `$SRC` when the temp target lacks them.
4. **Cleanup** — the temp target is removed; nothing else in `$SRC` is touched (R6
   falls out of the temp-dir isolation by construction).
5. **Regenerate + commit** the 15 files via `--self`; the diff IS the reconciliation
   review surface.
