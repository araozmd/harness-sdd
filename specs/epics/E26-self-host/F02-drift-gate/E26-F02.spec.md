# E26-F02 — glue divergence gate

E26-F01 made the source repo's `.claude/` glue installer-generated. This feature arms
the gate that keeps it true: an emitter change without a `--self` rerun, or a hand
edit to a generated file, must be caught by the suite (fail CLOSED) and surfaced by
`init.sh` (warn-only), not discovered by review.

## Requirements (EARS)

- **R1** — A new suite `tests/test_self_drift.sh` SHALL copy the source tree, run
  `--self` in the copy, and FAIL when any regenerated glue file differs byte-for-byte
  from the committed copy — catching both an emitter edited without regeneration and
  a hand-edited generated file. It runs under `verification.test_command`, which is
  the repo's CI-equivalent.
- **R2** — `--self` SHALL write `.claude/.glue-manifest`: one `cksum` line per
  regenerated glue file plus `.escalation-arming` when present, deterministic and
  committed. The manifest never lists itself.
- **R3** — When `init.sh` runs in the SOURCE layout (both `harness-install.sh` and
  the manifest present next to it), it SHALL print one warn-only line naming
  `--self` when any manifested file is missing or hash-mismatched; it SHALL stay
  silent in target layouts and when everything matches, and SHALL never fail the
  gate for staleness.
- **R4** — `VERSION` MINOR bump + CHANGELOG; `test_self_mode.sh` idempotence keeps
  covering the manifest (a second `--self` run changes zero bytes).
