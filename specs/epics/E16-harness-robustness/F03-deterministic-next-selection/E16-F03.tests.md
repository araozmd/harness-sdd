## Required fixture matrix
- Feature routes: every feature status; both `sdd` values where meaningful;
  absent/false/true autonomous; approval config true/false; draft/planned/pending/
  in-progress/done epic aliases; targeted existing/missing ids.
- Dependencies: done, pending, spec-ready, in-progress, in-review, missing,
  feature cycles, feature self-cycle, and a slice id referenced by a feature.
- Ownership: literal identity; feature override; epic fallback; unowned;
  mismatched; empty/unset; `@me` and `self` success/failure through a temporary
  PATH-stubbed `gh`; bare and targeted modes ignoring owners; empty/all-done
  boards taking precedence over unresolved mine identity.
- Slices: manifest absent, path absent, and present; known/missing repo;
  pending/spec-ready/in-progress/in-review/done/failed; merged true/false;
  satisfied, missing, failed, non-done, done-unmerged, cyclic, and self-cyclic
  upstreams; all-complete integration; unrelated top-level candidate that must
  not leak into selected-parent diagnostics.
- Determinism: reversed epic/feature/slice/dependency arrays, numeric ids such as
  `E2-F10` versus `E10-F2`, distinct numeric equivalents such as `E1-F01`
  versus `E01-F1`, repeated invocations, and duplicate exact-id rejection.
- Errors: unknown/duplicate/conflicting flags, missing values, invalid JSON,
  wrong root/collection/scalar types, missing required fields, inconsistent
  containment ids, malformed/duplicate relevant `workflow` and `umbrella`
  parents, missing-colon and sequence-shaped children under both relevant
  parents, inconsistent sibling indentation, mapping entries beneath scalars,
  invalid partial dedents from nested mappings (for both relevant parents),
  valid ignored nested mappings, intentionally ignored unrelated top-level
  malformed syntax, malformed relevant YAML scalar, malformed/duplicate
  manifest repo entry, repeated top-level `repos:` mappings (adjacent and
  separated), unreadable paths, and unsupported status.

## Behavioral checks
1. Execute every fixture through the independent prose oracle and the Node
   selector, compare normalized semantics, then compare raw bytes for reordered
   equivalent inputs.
2. For each success, blocked, halted, and error fixture, checksum the TaskStore,
   config, and manifest before and after invocation and require equality.
3. Run the selector from outside the repository against a source-layout fixture
   and a freshly installed `.harness/` fixture without path overrides.
4. Statically assert that the Orchestrator contract reports and uses the prose
   fallback for missing Node, nonzero selector execution, invalid JSON, and an
   unsupported schema version, and never re-derives a successful tool choice.
   The Reviewer manually checks the two fallback decisions.

## Non-functional checks
- `node --check tools/next-task.mjs`
- `sh -n tests/test_next_task.sh`
- At least 2,000 acyclic features select in less than five seconds on Node.js
  18+; fail only on the five-second contract, never on a frozen exact runtime.
- Full `verification.test_command` and `./init.sh` are green.
