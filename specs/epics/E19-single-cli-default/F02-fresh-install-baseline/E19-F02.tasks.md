      (`.harness/.harness-version` present, `.harness/.agents` deleted) with a host marker set
      must still report `baseline=` all five keys. This is the "upgrades must not silently
      narrow" guard and it is the only branch that is easy to get wrong.

      the function and nothing in `resolve_agents`.

      test — not the absence of `.agents` — is what stops an upgrade from silently narrowing.
