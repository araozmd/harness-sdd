# Fresh-install pre-check baseline = the detected host — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable
> check. The Reviewer fails the feature if any R-id lacks a passing check.
>
> All checks land in `tests/test_agents_host.sh` (created by E19-F01), a flat POSIX-`sh`
> script, so the "test name" is the section label its `pass "…"` line carries.
>
> **Environment discipline (inherited from E19-F01, mandatory).** Every detection-sensitive
> invocation runs as
> `env -i PATH="$PATH" HOME="$X/home" CODEX_HOME="$X/ch" [MARKERS…] sh "$SRC/harness-install.sh" …`,
> every installer-invoking run sandboxes `CODEX_HOME` under its own temp dir, no check freezes
> the exact `VERSION` string, and no check diffs a DO-NOT-TOUCH file against `main`.
>
> **Why `--print-agents` is the instrument.** The interactive pickers require a TTY, which a
> POSIX test suite cannot portably supply. E19-F01 R26 guarantees the picker's pre-check set
> and `--print-agents`' `baseline=` line come from the same helper, so asserting `baseline=`
> is asserting the picker.

## Concrete check sketches

**`baseline_fresh_is_host_only` (R1)** — empty dir, `CLAUDECODE=1`, `--print-agents` ⇒
`baseline=claude` exactly. Assert the literal single-key line: `claude gemini …` and any
union that merely *contains* `claude` must fail. This is the host-only-not-host-plus-claude
check.

**`baseline_fresh_undetected_is_all` (R2)** — empty dir, no marker ⇒ `baseline=` lists all
five keys, sorted.

**`baseline_upgrade_keeps_persisted` (R3)** — install with `--agents=gemini`, then ask
`--print-agents` with `CLAUDECODE=1` ⇒ `baseline=gemini`.

**`baseline_legacy_upgrade_is_all` (R4)** — install, then `rm .harness/.agents` (leaving
`.harness/.harness-version`, i.e. the pre-E08 shape), then ask `--print-agents` with
`CLAUDECODE=1` ⇒ `baseline=` all five, **not** `claude`. Write this one first; it is the
"upgrades must not silently narrow" guard and the branch most likely to be wrong.

**`no_tty_default_unchanged` (R5)** — `CLAUDECODE=1`, no override, non-TTY stdin ⇒ all five
front-ends stamped and persisted.

**`baseline_single_helper` (R6)** — source: `resolve_agents`'s interactive branch and the
`--print-agents` path both call `precheck_baseline`; no baseline logic is duplicated.

**`prior_agents_unchanged` (R7)** — source: the `PRIOR_AGENTS` block still carries its
`grep -vx codex` legacy exclusion.

**`baseline_fresh_removes_nothing` (R8)** — pre-seed the sandboxed `$CODEX_HOME/prompts` with
a foreign file plus a `.sdd-pr-loop.owners` ledger naming another target; install into an
empty dir with `CLAUDECODE=1 --agents=host` (the non-interactive proxy for confirming the
narrowed pre-check); both survive untouched.

**`existing_install_never_narrows` (R9)** — install with `--agents=claude,gemini`, then re-run
non-interactively with `CLAUDECODE=1` and no override: `.harness/.agents` is unchanged and
`GEMINI.md` still exists.

**`docs_document_fresh_default` / `docs_document_retoggle_path` (R10, R11)** —
`docs/INSTALL.md` describes the first-install pre-check, the upgrade exception and the
undetected case; and carries a re-toggle section naming `.harness/.agents` and stating that a
re-run applies both adds and removes. The `harness-install.sh` header no longer claims the
interactive path pre-checks "ALL on a fresh install".

**`version_and_changelog` (R13)** — `VERSION` is greater than the version E19-F01 shipped by a
MINOR step, and `CHANGELOG.md` has a matching entry. Compare **by parsed components**, never
by freezing the literal string.

## Behavioral / end-to-end checks (Reviewer, by hand)

- From inside a real Claude Code session, run the installer interactively into a **new**
  scratch repo and confirm the picker pre-checks `claude` alone, with the other four
  unchecked and still togglable.
- Toggle `gemini` on before confirming and confirm `GEMINI.md` appears — the pre-check is a
  default, not a restriction.
- Re-run the installer interactively against that repo and confirm it pre-checks
  `claude gemini` (the persisted set), not `claude`.
- Toggle `gemini` back off, confirm, and check `GEMINI.md` is removed — the documented
  re-toggle path (R11).
- From a plain terminal, run the installer interactively into a new scratch repo and confirm
  all five are pre-checked (undetected ⇒ ALL).

## Non-functional checks

- Lint: `verification.lint_command` is empty — n/a. The installer must stay POSIX `sh`.
- Types: `verification.typecheck_command` is empty — n/a.
- `./init.sh` exits 0 in the harness source repo and in an installed target.
