## Behavioral / end-to-end checks
- R4's fixture builds `1 2 3` plus an empty `round-4/`: the verdict must stay
  `non-converging`. If the empty round were counted as `0`, the last-3 window would contain a
  zero and the verdict would flip to `converging` — a false all-clear on the exact PR shape
  this feature exists to catch.
- The `converging` fixture is asserted **not** to contain the split instruction, so the advice
  has to be earned rather than printed unconditionally.
