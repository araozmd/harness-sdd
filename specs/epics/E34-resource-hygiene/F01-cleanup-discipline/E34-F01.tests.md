## Behavioral / end-to-end checks
- Build a disposable fixture: a temp Git repo with `scratchpad/E01-F01-builder/`,
  `scratchpad/E01-F02-reviewer/`, `scratchpad/not-a-feature-dir/`, and a symlinked entry
  pointing outside `scratchpad/`, plus a fixture `state/tasks.json` where `E01-F01` is
  `done` and `E01-F02` is `in-review`. Run `tools/sweep-scratch.sh` (dry-run): confirm
  `E01-F01-builder` reports `eligible`, `E01-F02-reviewer` reports `skipped:
  status:in-review`, the non-matching dir reports `unrecognized`, and the symlink entry
  reports `skipped: <anomaly>` — nothing on disk changes. Re-run with `--apply`: confirm
  only `E01-F01-builder` is removed, byte-identical everything else remains, the reported
  bytes-reclaimed total matches that one directory's size, and the exit code is 0.
- Repeat with a corrupted/unparseable fixture `state/tasks.json`: confirm the tool exits
  non-zero, removes nothing, reports no per-entry verdicts at all (the scan never reached
  classification), and every path from the first run still exists afterward. This is a
  distinct control from the R4 "not found"/"status ≠ done" cases — do not collapse the
  two into one test.
- Exercise the scoped-argument path (`tools/sweep-scratch.sh E01-F01`) against the same
  fixture and confirm `E01-F02-reviewer` is not even reported (out of scope for that
  invocation), only `E01-F01-builder`.
- For R9/R10 (doc-grep): follow `tests/test_scratch_and_disk_preconditions.sh`'s own
  documented technique — section-scope each file to the exact heading/labeled sub-item
  before asserting, sentence-anchor each assertion to the sentence carrying the
  obligation (`[^.]{0,N}`), and add a negative-space check that the new text carries no
  optionality marker ("may", "should", "when convenient"). Do not grep whole files, and
  do not let a `(3f)` assertion accidentally also match inside `(3d)`/`(3e)`'s blocks.

## Non-functional checks
- Lint: n/a (`lint_command` unset in `harness.config.yaml`).
- Types: n/a (`typecheck_command` unset).
- Shell portability: `tools/sweep-scratch.sh` and its test suite must parse and pass under
  whichever `sh` `tools/run-tests.sh` selects (dash and bash-as-POSIX), consistent with
  every other suite (see `tools/run-tests.sh`'s own note on shell-dependent failures).
