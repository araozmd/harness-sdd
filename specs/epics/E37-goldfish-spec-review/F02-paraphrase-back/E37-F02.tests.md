# Doc-critic paraphrase-back comprehension mode at the feature-spec checkpoint — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test,
> and every row names the mutant that kills it. The Reviewer fails the feature if any R-id
> lacks a passing test, or if a named mutant survives.
>
> **Suites.** The feature's rows live in the existing POSIX `sh` suite `tests/test_doc_critic.sh`
> (DC — source tree; every existing function and anchor stays) and, for the installed contract,
> `tests/test_install.sh` (TI). Both run under `tools/run-tests.sh`'s strictest shell (dash on
> CI): `set -eu`, `|| true` on any `grep -c`, `rc -eq N` never a lookup miss's exact code.
> Every heading slicer loads `tests/lib/fence.awk` and calls `fence_delim($0)` first
> (`tests/test_change_size.sh` R9d scans every suite for the bare idiom; `agents/reviewer.md`
> carries four fences). Section bounds are line numbers (`grep -n '^## …' | cut -d: -f1`)
> compared as integers; a spanned section is the fence-aware text from its heading to the next
> `^## `. Co-occurrence anchors fold newlines (`tr '\n' ' ' | tr -s ' '`) and quote **whole
> sentences from their subject** (lesson 2026-10-26); each gate sentence has a mutant below, and
> every negative is one the Builder has shown non-vacuous against the pre-change blob (lesson
> 2026-10-27 — a negative built from words that markdown emphasis splits is vacuous). The suite
> never reads `VERSION` as a literal, never diffs a DO-NOT-TOUCH file against `main` (`cksum`
> instead), never writes `state/` or a live spec.
>
> **Pre-change RED (Builder obligation).** Confirm each anchor RED on the pre-change blob
> (`git show HEAD:<file>` for source rows; an install from a `git stash`-ed tree into a second
> temp dir for TI) before trusting it, one anchor at a time — the whole-suite RED hides which
> one is vacuous — and record the check in `progress/E37-F02/builder.md`.
>
> **What is not tested by machine.** The critic's *behavior* under the new text (whether a
> spawned critic actually writes a paraphrase) is not a suite row: the suites pin the contract
> text; the first live exercise is E37-F03's checkpoint, and the `C12` ledger row names the
> evidence that would remove the mode. The *Behavioral checks* below give the Reviewer the
> one observation available now.

after each prose mutant an installed row reads. Record free space before and after. A test-side
mutant runs in a private real copy of the repo (`git archive HEAD | tar -x`), never a symlink
farm (lesson 2026-11-09 r3).
