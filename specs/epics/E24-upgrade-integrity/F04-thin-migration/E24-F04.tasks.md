## The comparison

- [ ] **T4** (R1, R2, R3) — Add `prose_tier_blockers <harness-dir> <umbrella-body-dir>`: for
      each entry in `HARNESS_BODY_PROSE`, run `diff -rq` between the target's copy and the
      umbrella body's copy; on non-zero exit, emit one line per differing path. Prints nothing
      when every entry is identical. Do **not** walk the trees by hand (`.plan.md` → *The
      comparison*). Three constraints, each of which the naive version gets wrong:
      - **`-q` is mandatory** — two tier entries (`AGENTS.md`, `specs/glossary.md`) are
        regular files, and `diff -r` on two files prints hunks with no filename at all.
      - **Rewrite `Only in <dir>: <name>` to `<dir>/<name>`** before emitting. That form
        never contains the joined path, so R3 is unsatisfiable without the normalisation.
      - **Capture without aborting** — the installer is `set -eu` and `diff` exits non-zero
        exactly in the case that matters. Capture inside an `if` or with `|| :`, and keep the
        exit status separately.
- [ ] **T5** (R2, R3) — In the same function, fail closed: an entry missing on either side,
      and a `diff` that does not resolve on `PATH`, both count as blocking. A missing entry
      makes `diff` exit 2 with its message on **stderr**, so a stdout-only capture names
      nothing — either fold stderr in or synthesise the reason line, and make sure the line
      contains the tier-relative path either way.
