## Anti-tautology

- **Every stub assertion is paired with a full-copy control.** "The file contains the
  sentinel" is satisfiable by a body that was never written; each case first asserts the same
  path in a non-umbrella install is a real copy (no sentinel, and a known body substring
  present). This is the fixture-precondition failure that produced four vacuous green tests
  in the E99-F11 session — a stray file the installer prunes, a config rewrite that silently
  no-opped, a SIGPIPE fixture below the pipe buffer, and a newline path git reported `??`.
- **R7 carries a positive control in the same run.** Bump `VERSION` in the source, re-run the
  cascade, then assert the stubs are byte-identical **and** that a standalone-tier file
  (`.harness/.harness-version`, and one `tools/` file) *did* change. Without the control, R7
  passes on a re-run that did nothing at all.
- **R6 moves the umbrella away**; it does not merely omit `umbrella.root`. Omitting the key
  exercises R5's full-copy path, which would pass with R6 unimplemented. The reachable case
  runs on the same fixture so "exit 0" cannot come from a check that never executed.
- **R9 asserts bytes, not existence.** Capture the full-copy body's checksum before the
  cascade, compare after: a swap to stubs changes bytes while leaving every path present.
- **R5 asserts the sentinel is absent from the whole `.harness/` tree**, not from one sampled
  file. A per-file probe is the witness-file anti-pattern `harness-owned-paths.sh` already
  documents — it is only ever as complete as the last bug report.

## Regression contract (this feature must change nothing here)

- **E24-F01's drift guard and E24-F02's landing audit pass unchanged**, in both layouts.
  Stubs are ordinary tracked files at the same pathspecs; if either needs a line changed,
  the design has drifted from ADR-0004 and that is the finding, not a test to update.
- `tools/harness-owned-paths.sh` is untouched, and its existing assertions stay green.
- The front-end glue suites (`test_install.sh`, `test_pr_loop.sh`, `test_model_routing.sh`,
  `test_agents_host.sh`) stay green with no assertion edits — all glue is standalone-tier.

## Suite-wide constraints

Never assert an exact `VERSION` literal (R7 compares two runs, it does not name a version);
never couple a CHANGELOG assertion to the top version; never `git diff` a DO-NOT-TOUCH file
against `main`; every fixture under its own `mktemp -d`; sandbox `CODEX_HOME` **and** `HOME`
on every `harness-install.sh` invocation.

## Non-functional

- `sh tools/run-tests.sh` fully green.
- The suites must pass under `dash` (`/bin/sh` is dash on Ubuntu CI).
- `sh -n harness-install.sh`, `bash -n init.sh` clean; `sh tools/change-size.sh` within budget.
