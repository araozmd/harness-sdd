# Feature-level park — Task Breakdown

Ordered so each task leaves the tree green. One commit per task.

- [ ] **T1 — Schema: the `parked` object.**
      `store/tasks.schema.json`: optional `parked` on a feature, `required: [reason]`,
      `reason` and `unblocked_by` both `minLength: 1`. Covers **R3**.

- [ ] **T2 — Fallback validator agreement.**
      `tools/validate-board.py`: the zero-dep path enforces the same two rules, so a machine
      without `jsonschema` does not accept a board the schema rejects. Covers **R3 (fallback)**.

- [ ] **T3 — The blocker record.**
      `tools/next-task.mjs` `featureBlockers`: push `{code: 'parked', detail: <reason [+
      unblocked_by]>}` beside `gated-epic`. **Do not touch `featureRoute`.**
      Covers **R1, R4, R6**.

- [ ] **T4 — Legible dependents.**
      Same file: render a parked unmet dependency as `id=status (parked: reason)`.
      Covers **R5**.

- [ ] **T5 — The park holds against transitions.**
      `tools/tasks-lock.py`: `set-status` refuses a parked feature, naming the reason and the
      unpark step; exits non-zero and writes nothing. Covers **R8**.

- [ ] **T6 — Tests.**
      `tests/test_feature_park.sh` with every R-id from the contract, each park case carrying
      its unparked positive control in the same run. Covers **R2, R7, R9** and pins the rest.

- [ ] **T7 — Docs.**
      `docs/WORKFLOW.md`: the park row in the route/status table, plus how to park/unpark and
      the fact that a park composes with every status.

- [ ] **T8 — Release.**
      `VERSION` MINOR bump, `CHANGELOG.md` entry. Run `sh tools/run-tests.sh`,
      `dash tests/test_feature_park.sh`, `sh tools/change-size.sh`, and the mutation battery
      from the test contract **before** opening the PR.

## Verification gate

`sh tools/run-tests.sh` (all suites) + `sh tools/change-size.sh`. Suites must also pass under
`dash`, since CI `/bin/sh` is dash.
