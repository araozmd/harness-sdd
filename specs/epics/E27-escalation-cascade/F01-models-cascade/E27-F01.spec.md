# E27-F01 — Umbrella `models:` cascade

Arming sonnet-builder/opus-escalation across harness-sdd + 15 umbrella children
(2026-09-05) required editing 16 per-child `models:` blocks by script — the exact toil
a cascade removes. One coordinator edit should re-tier every child on the next run.

The resolution hangs off the choke point that already exists: `umbrella_body_dir`
resolves the coordinator's `.harness/` from the cascade environment OR the child's
persisted `umbrella.root`, so the cascade works on a standalone child re-run too, not
only inside `--umbrella` (structural over compliance-dependent — no loop-scoped side
channel to forget).

## Requirements (EARS)

- **R1** — When a target resolves an umbrella body (`umbrella_body_dir` non-empty) and
  its own `models.<role>` → `models.default` chain yields absent or `inherit`, the
  system SHALL resolve the tier from the coordinator's
  `<umbrella>/.harness/harness.config.yaml` `models:` block (same role → default
  order) before falling back to the built-in `inherit`.
- **R2** — A child's own explicit, recognized, non-`inherit` value SHALL always win
  over the coordinator's; an unrecognized child value SHALL warn once (existing
  behavior), then cascade as if `inherit`.
- **R3** — When a role's tier resolves but the child config has no
  `models.pin.<front-end>.<tier>`, the system SHALL consult the coordinator's same pin
  key before the built-in floating-alias table; a child's own pin always wins, and
  whichever pin wins is validated by the existing pin guards (`inherit`-pin,
  OpenCode `provider/model` shape).
- **R4** — The escalation arming verdict (`write_escalation_arming`) SHALL be computed
  from the cascaded resolution, so a coordinator-only `models:` edit re-arms every
  child in the same cascade pass with no child edits.
- **R5** — When at least one role resolves from the umbrella, `install_one` SHALL
  print one report line for the target naming each role's tier and source
  (`own` | `umbrella`); roles resolving to `inherit` are summarized, not listed.
- **R6** — A target that resolves no umbrella body (single-repo install, or the
  coordinator itself) SHALL behave byte-identically to v0.72.1: no coordinator lookup,
  no report line, identical artifacts.
- **R7** — An unrecognized tier in the COORDINATOR's block SHALL warn once, naming the
  coordinator as the source, and resolve as `inherit` — never a fatal error.
- **R8** — `VERSION` MINOR bump + CHANGELOG entry; new suite
  `tests/test_models_cascade.sh` pins R1–R7 (cascade fixture: coordinator tiers + one
  overriding child + single-repo non-regression).
