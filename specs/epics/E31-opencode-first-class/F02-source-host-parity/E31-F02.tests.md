## Behavioral / end-to-end checks

- **Idempotence (R1).** Run `--self` twice; the second run must change no tracked file
  (byte-identical glue, `git status` clean for `.opencode/` and `opencode.json`).
- **OpenCode resolves source glue (R8).** With `command -v opencode`, run `opencode serve` in
  the repo and `GET /command` / `GET /agent`; assert `/sdd-next` and `builder-heavy` are
  present. If OpenCode is unavailable in CI, gate on `command -v opencode` and report skipped;
  the static assertions in `test_self_mode.sh` remain mandatory.
- **No machine leakage (R4).** Run `--self` with a `.harness/.opencode-parallel` containing
  `supported` present in a fixture; the source output must be unchanged (gate forced off).
  Also assert no `.opencode-parallel` was written into the source tree.

## Non-functional checks

- Lint: `sh -n harness-install.sh` clean.
- Tests: `sh tests/run-tests.sh` green (or the configured `verification.test_command`).
- `git status --porcelain` after `--self` shows only intended glue changes.
