## Behavioral / end-to-end checks

- **Idempotence (R1).** Run `--self` twice; the second run changes no tracked file —
  `.opencode/`, `opencode.json`, `.claude/`, `.codex/`, `.agents/`, `.escalation-arming`, and
  `.claude/.glue-manifest` are byte-identical (`test_self_mode.sh`'s existing R6 snapshot
  block extended with the OpenCode paths).
- **OpenCode resolves the source glue (R9).** With `command -v opencode`, run an `opencode`
  agent/command listing in the source repo and assert `/sdd-next` and the `builder-heavy` and
  `pr-fixer` agents are present. If OpenCode is unavailable in CI, gate on `command -v
  opencode` and report skipped; the static assertions (role set in `opencode.json`, command
  files present — `test_codex_native.sh`'s R9 arm plus `test_self_mode.sh` R2/R7) remain
  mandatory.
- **No machine leakage (R4).** Run `--self` once with `--with-opencode-parallel=true` and once
  without; the source output must be byte-identical, and neither
  `.opencode/command/sdd-fix-parallel.md` nor `.opencode-parallel` may appear in either. The
  temp install's fresh `TARGET` cannot see a source-root marker, so the CLI flag is the only
  lever and the equality is what proves it was neutralised (a lone absence check would not).
- **Explicit root, not a stripped prefix (R7, finding 4045793773).** The source
  `.opencode/agent/pr-fixer.md` must carry a real resolution root. Assert the FOLDED body with
  a two-token positive anchor (`mentions … repository root`) AND a negative that no empty
  inline-code span survives, with a planted positive control so the negative predicate cannot
  go dead. `test_self_mode.sh` runs both over the freshly GENERATED fixture; its committed
  twin in `test_source_shims.sh` reads `$SRC` directly. Verify the whole test reds on the
  pre-change text (revert the `self_transform` rules, re-run `--self`); it must fail naming
  the missing root, not a downstream assertion.
- **Drift gate both arms (R6).** Green: a pristine copy's regenerated OpenCode glue equals
  the committed bytes. Red: a copy whose `gen_opencode_json` description is mutated, with
  `--self` re-run, produces a non-empty `glue_diff` naming the OpenCode path. `init.sh` in the
  source layout warns on a hand-edited `.opencode/command/sdd-next.md` and exits 0.

## Non-functional checks

- Lint: `sh -n harness-install.sh` clean.
- Tests: `tools/run-tests.sh` green (or the configured `verification.test_command`).
- `git status --porcelain` after `--self` shows only intended glue changes; `.opencode-parallel`
  is git-ignored (`.gitignore` already carries `/.opencode-parallel`, added by E31-F01) and the
  gated command is absent.
- `.opencode/command/` and `.opencode/agent/` are never added to `.gitignore` — they are
  tracked generated glue.

## Additional regression suites

- **`tests/test_source_shims.sh` (R2, R9).** This suite reads `$SRC` directly and will fail on
  F02 unless edited: its absence loop (`:90-104`) asserts `$SRC/.opencode` does not exist, and
  its `KNOWN_GAPS` xfails (`:76-77`) assert `builder-heavy:opencode` and `pr-fixer:opencode`
  are still unregistered. The edit drops `.opencode` from the absence loop and deletes both
  `KNOWN_GAPS` lines (both roles are registered after F02 — `builder-heavy` via the
  `opencode-json` mechanism, `pr-fixer` via `opencode-file`), letting the suite's general
  registration rule cover them. Without this edit the suite fails the moment the `.opencode/`
  glue is committed.
- **Codex arming stays focused (H2).** The `models` fixture (`test_codex_native.sh:56-67`) and
  the R11 protected-Builder loop (`:91-113`) must pass explicit `--agents=claude,codex` to
  their `--self` runs (`:57`, `:61`, `:101`, `:113`). A bare `--self` now also selects
  `opencode`, whose `neither` verdict makes the conservative AND `blocked` and reds the
  `armed`/`codex=unstamped` expectations for a reason unrelated to what those tests prove.
  F02's own OpenCode arming verdict is pinned by R5 instead.
- **`tests/test_installer_toggles.sh:1520-1534` is expected to stay green unchanged (M1).**
  It pins E31-F01's shared-body source-checkout clause, which F02 makes factually stale but
  deliberately does **not** edit (the shared adapter is F01-owned; the correction is a named
  follow-up recorded in the spec's Open questions). If this suite reds, F02 has touched the
  F01 surface contrary to the plan's DO-NOT-TOUCH — the failure is a boundary violation, not
  a test to update.

## Lessons-driven probes the Builder/Reviewer must run

- **A fixture copied from the repo inherits the artifact under test** (`progress/lessons.md`
  2026-09-05). The green drift/self fixtures must **delete** `opencode.json` and `.opencode/`
  before `--self`, or R1/R6 prove the repo's state, not the code's behavior. In
  `test_self_drift.sh` this deletion is the falsifiability condition: without it the
  regenerated-vs-committed comparison can be green on a stale committed artifact.
- **Per-surface pinning (2026-09-17).** R6 asserts the OpenCode path on **every** surface that
  carries the byte contract: `glue_diff`, the `.claude/.glue-manifest` entries, and `init.sh`'s
  warn. Asserting only one leaves the others unproven.
- **Ordering assertions (2026-09-17).** Where the test checks that OpenCode is in the default
  selection, assert the resolved set as an ordered/spaced list, not a label.
- **Frozen-fixture exclusions (2026-09-16).** Do **not** add or remove entries in
  `tests/test_codex_native.sh`'s `_regenerated` set (`:222`); F02 changes no regenerated
  command body. If the oracle reds, the emitter changed contrary to the plan.
- **A prefix-strip transform can leave an EMPTY root, not just a missing prefix
  (2026-09-18, finding 4045793773).** A whole-body `.harness/` strip turned the pr-fixer
  shim's `installed in` / `mentions against` sentences into empty inline-code spans. A test
  that only greps for a surviving `.harness/` token (R7's original `opencode_glue_source_layout`)
  is green on that broken output because the failure is an ABSENCE, not a leftover. Pin the
  replacement positively (two-token `mentions … repository root`) and the broken shape
  negatively (no empty inline-code span), and verify RED by reverting the transform.
- **`--self` claimant-preserving selection.** Assert `--self --agents=claude` leaves no
  `.opencode/` and no `opencode.json`, and `--self --agents=codex` leaves the shared
  `.agents/skills/` units in place (F01's deselect-last contract is not regressed by F02's
  default change).
