## Behavioral / end-to-end checks

- **OpenCode resolves the seven workflows (R1/R4).** In a temp project with
  `--agents=opencode`, run `opencode serve` and `GET /command`; assert `sdd-next`, `sdd-new`,
  `sdd-plan`, `sdd-drill`, `sdd-fix`, `sdd-fix-parallel`, `sdd-pr-loop` are present
  (`source:"skill"`). This is the empirical oracle the epic's probe used. If OpenCode is not
  installed in CI, gate this check on `command -v opencode` and report it as skipped, not
  failed — the unit/integration assertions above remain mandatory.
- **Gate holds in OpenCode (R5).** With `.harness/.opencode-parallel` absent or `sequential`,
  invoke `/sdd-fix-parallel` in OpenCode and confirm it stops before spawning workers and
  names `/sdd-test-concurrency`; then write `supported` and confirm the workflow proceeds.
  Gate on `command -v opencode`; otherwise assert the precondition text in the generated
  `SKILL.md` (the mandatory half).
- **Deselect-last only (R3).** The reclaim test must be a two-claimant fixture
  (`codex,opencode` → deselect one → units present; → deselect the other → units gone). A
  single-claimant test cannot detect the silent-destructive regression.

## Non-functional checks

- Lint: `sh -n harness-install.sh` clean.
- Tests: `sh tests/run-tests.sh` green (or the configured
  `verification.test_command`).
- No new dependency: the suites remain POSIX `sh`, zero network.
