> mutant it kills**. The Reviewer fails the feature if any R-id lacks a passing test, or if
> the named mutant survives. "Live" rows run only when the gate selects that major. They
> print `skip - …` otherwise, and the hermetic rows still run.

## Behavioral / end-to-end checks
- **Both majors, one host (R3, R4, R6, R8).** With 2.0.32 on PATH:
  `sh tests/test_codex_native.sh` must print `ok - opencode_target_resolves (R3, live 2.x)`
  and `ok - opencode_source_host_resolves (R4, live 2.x)`. Then run
  `PATH="$HOME/.local/share/mise/installs/opencode/1.18.35:$PATH" sh tests/test_codex_native.sh`;
  it must print the existing E31-F02 `(R9, live)` line (that is `E31-F02:R9`, not this spec's R9) and `ok - opencode_target_resolves (R8, live 1.x)`.
- **Daemon baseline (R6).** Record `pgrep -af 'opencode.exe serve'` before the runs above.
  It must be identical afterwards. Repeat once with a deliberately failing R3 assertion
  (temporary local edit, not committed) to show the `finally` path reaps the server.
- **Absent binary (R2).** `PATH=/usr/bin:/bin sh tests/test_codex_native.sh` prints
  `skip - live opencode probe unavailable; …` and passes.
- **Unsupported major (R2).** A stub `opencode` printing `3.0.0` first on PATH ⇒ the suite
  prints `skip - live opencode probe: … unsupported major 3 …` and passes.
- **No glue drift (R1).** `sh harness-install.sh --self && git status --porcelain` shows no
  change under `opencode.json`, `.opencode/`, `.claude/`, `.codex/`, `.agents/`.
- **Helper on the real 2.x (R9).** With an isolated `XDG_*` / `HOME`, run
  `sh tools/opencode-model-helper.sh <tmp-config>`. Afterwards,
  `opencode service status` (same env) prints `stopped` and `pgrep` shows no new
  `serve --service`.

## Non-functional checks
- Lint: `sh -n tools/opencode-model-helper.sh` and `sh -n tests/test_opencode_compat.sh`
  clean.
- Tests: `tools/run-tests.sh` green. The new suite is auto-discovered under `tests/`.
- Runtime: the live 2.x arm adds ≤ 30 s on a warm host.
- Secrets: no assertion message, `print`, or committed fixture contains a `serve` password,
  and the fixture holds model ids only.
