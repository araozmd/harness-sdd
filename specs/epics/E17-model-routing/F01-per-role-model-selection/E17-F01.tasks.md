- [x] **T5** (R5, R6, R7, R8, R10) — Add the built-in tier→native alias table and
      `resolve_model <front-end> <role>`. Order: tier → `pin.<front-end>.<tier>` (verbatim

      yields empty. `codex`/`opencode` have no built-in alias, so an unpinned tier there
      yields empty plus one stderr info line naming the `pin.` key to set. An `opencode`
      pin lacking `/` warns and yields empty. All diagnostics go to stderr,
      de-duplicated to one line per (front-end, tier).

- [x] **T6** (R17, R18) — Add `models_any <front-end>` — exit 0 iff any role in
      `$MODEL_ROLES` resolves to a non-empty value for that front-end.
