## Behavioral / end-to-end checks
- Run `./init.sh` and confirm it exits 0 before hand-off.
- Run the configured verification command and confirm the extended `tests/test_install.sh` passes.
- Perform a fresh install into a temporary target and confirm `AGENTS.md`, selected `CLAUDE.md`, and selected `GEMINI.md` contain the managed marker block and optional local-override guidance.
- Re-run the installer over the same target after appending a custom `.gitignore` entry and confirm the custom entry remains while local prompt ignore entries appear exactly once.

## Non-functional checks
- Lint: none beyond existing shell test style.
- Types: none.
- Portability: no new dependencies; generated guidance must be readable by AGENTS.md-compatible CLIs and must not assume a CLI-specific loader for the portable `AGENTS.local.md` convention.
