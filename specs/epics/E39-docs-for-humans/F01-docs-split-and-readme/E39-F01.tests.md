# Docs for humans, slice 1 — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test,
> and every row names the mutant that kills it. The Reviewer fails the feature if any R-id
> lacks a passing test, or if a named mutant survives that is not a listed known limit.
>
> **Suite.** A new POSIX `sh` suite, `tests/test_docs_for_humans.sh` (DH), executable,
> `set -eu`, `LC_ALL=C`, `trap 'rm -rf "$T"' EXIT`, `trap 'exit 1' HUP INT TERM`, `fail`/`pass`,
> run by `tools/run-tests.sh` under the strictest shell it can probe (dash on CI) — assert
> `rc -eq N`, never a shell-dependent code; capture with `set +e; …; rc=$?; set -e`.
> `ROOT` is the repo; `FX="$ROOT/tests/fixtures/doc-cite"`; `HUMAN_DOCS` is the registry string
> the spec pins (R6). Heading slices go through `tests/lib/fence.awk` (`fence_delim($0)` first
> — the house idiom; a naive `/^```/` toggle is the defect E99-F131 closed). Rows that mutate a
> doc copy it under `$T` first and never touch `$ROOT`. The R8 rows build a two-commit git repo
> under `$T` (`git init -q`, `user.name`/`user.email` set locally, `GIT_CEILING_DIRECTORIES="$T"`)
> so the tool is exercised without diffing this repository against `main`. Every row is dispatched
> from one flat list through `row <name>`, which fails the suite when the row returns without a
> `pass` line under its own name; the suite ends with the "defined but not dispatched" sweep over
> every `R*()` function (the E37-F03 shape). The suite never reads `VERSION` as a literal.
> Installer behaviour (R2, R12 wiring) lives in `tests/test_install.sh`.
>
> **Mutants.** Each row below names the smallest edit that must turn it RED. The Reviewer's
> mutation campaign applies each one in isolation on a copy (`cp` / `mv …mutbak` discipline from
> `agents/reviewer.md`), confirms the mutation applied (`grep` the planted text first), and
> restores between mutations.

## Behavioral / end-to-end checks

- **Render.** Open the branch on GitHub (or a Mermaid-capable preview): the README loop
  diagram, the CONCEPTS state diagram render; the logo shows at the top of the README; the
  wordmark and social preview open. Confirm no diagram falls back to a code block.
- **Five-minute read.** Read `README.md` top to bottom; stop the clock at the end of
  `## Documentation`. Over five minutes, or any paragraph that needs a second read, is a
  rejection with the paragraph named.
- **Move proof.** `sh tools/docs-move-check.sh main` on the branch: exit 0, `0 vanished tokens`;
  read every `DROPPED-LINE` — each must be a rewritten human sentence (its tokens survive),
  never a contract (an exit code, env var, flag or precedence rule). Then
  `git diff -U0 main -- tests/ | grep '^[-+][^-+]' | sed 's#docs/agents/README.md#README.md#' | sort | uniq -u`
  — the only survivors are the new `test_install.sh` function and the suite skeleton.
- **Citations.** `python3 tools/doc-cite-check.py` at the repo root: exit 0. Then break one
  heading in a scratch copy and rerun with `--root`: exit 1 naming the citing file and line.
- **Install.** `sh harness-install.sh --agents=all <tmp-target>`: `<tmp-target>/.harness/docs/agents/README.md`
  present and identical; `find <tmp-target>/.harness -name assets` empty; both tools executable.
  `sh harness-install.sh --self` leaves `git status` clean.
- **Thin child.** The existing umbrella suites (`sh tools/run-tests.sh tests/test_umbrella.sh`)
  stay green — they copy the real body, so a nested docs/agents directory is exercised by the
  thinning walk without a new fixture.
- **Mutation campaign.** Apply each row's mutant in isolation; every one reds its row; restore.

## Non-functional checks

- `sh -n tools/docs-move-check.sh` and `dash -n` (via `tools/run-tests.sh`'s preflight) clean;
  `python3 -m py_compile tools/doc-cite-check.py` clean.
- `python3 tools/tasks-pair-check.py` / `plan-cite-check.py` / `readiness-check.py` exit 0 on
  this feature directory (Reviewer checks 7–9).
- `sh tools/change-size.sh --base main` at or under the advise tier, or one recorded line why not.
- `sh tests/test_suite_hygiene.sh` green (the new suite traps EXIT and HUP/INT/TERM).
