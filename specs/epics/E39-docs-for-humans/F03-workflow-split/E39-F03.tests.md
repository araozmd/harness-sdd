# Docs for humans, slice 3: WORKFLOW split — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test,
> and every row names the mutant that kills it. The Reviewer fails the feature if any R-id
> lacks a passing test, or if a named mutant survives that is not a listed known limit.
>
> **Suite.** The slice-1 suite `tests/test_docs_for_humans.sh` (DH) gains the rows below under a
> `# ---- E39-F03` comment; new row functions are named `F03_R<n>_<slug>` (the `R<n>` is this
> spec's R-id); the slice-2 dispatch sweep already matches them. The house helpers are reused,
> never duplicated: `slice`, `unfenced`, `folded`, `mermaid_blocks`, `has_heading`, `nlines`,
> `link_targets`, `broken_links`, `anchor_problems`, `mirror`, `registry_each`, `index_rows`,
> `section_diagram`, and the two helpers this slice generalises in place (`shape_problems`,
> `diagram_problems … <type>`). Rows that mutate a doc copy it under `$T` first and never touch
> `$ROOT`; the suite never reads `VERSION` as a literal and never git-diffs a DO-NOT-TOUCH file
> against `main`. Exit codes are asserted as `rc -eq N`. Installer behaviour (R9 shipping) lives
> in `tests/test_install.sh`; the move proof (R1's `docs-move-check.sh` clause) and the path-only
> diff (R6) are Reviewer behavioural checks because a permanent suite must not diff against
> `main`.
>
> **Mutants.** Each row names the smallest edit that must turn it RED. The Reviewer's mutation
> campaign applies each one in isolation on a copy (`cp` / `mv …mutbak` discipline from
> `agents/reviewer.md`), confirms the mutation applied (`grep` the planted text first), and
> restores between mutations.

## Behavioral / end-to-end checks

- **Render.** Open the branch on GitHub (or a Mermaid-capable preview): both WORKFLOW diagrams
  render; the state diagram shows the `spec-ready` → `in-progress` edge labelled with the
  autonomous skip and the single `done` edge labelled with the merge; the flowchart shows the
  two `needs-human` routes and the `auto_merge` fork.
- **Five-minute read.** Read `docs/WORKFLOW.md` top to bottom. Over five minutes, or any
  paragraph that needs a second read, is a rejection with the paragraph named. Then, for every
  absolute in the doc (`never`, `always`, `nothing`, `every`, `all`, `only`), open the owning
  counterpart section from the plan's *Accuracy table* and confirm the sentence; a sentence the
  contract does not support is a rejection even if the regex pin passes.
- **Move proof.** `sh tools/docs-move-check.sh <base>`: exit 0, `0 vanished tokens, 6 dropped
  lines, <M> moved lines, 4 human docs examined` (WORKFLOW, RATIONALE, SPEC-FORMAT, UMBRELLA —
  the human docs that differ from the base); the six `DROPPED-LINE` lines are exactly the
  sibling-doc lines R1 names. Then `diff <(git show <base>:docs/WORKFLOW.md)
  docs/agents/WORKFLOW.md`: only the blockquote and the six retargeted link lines differ.
- **Path-only diff.** The R6 `git diff -U0 … | uniq -u` command: exactly two survivors, the
  old and the new `for _f in` line of `test_docs_for_humans_installed_contract`.
- **Citations.** `python3 tools/doc-cite-check.py` at the repo root: exit 0. Then, in a scratch
  mirror, revert the `docs/agents/INSTALL.md` pointer to `docs/WORKFLOW.md` and rerun with
  `--root`: exit 1 naming `docs/agents/INSTALL.md`.
- **Install.** `sh harness-install.sh --agents=all <tmp-target>`: both WORKFLOW files present
  under `<tmp-target>/.harness/docs/` and identical to source; the installed
  `.claude/commands/sdd-next.md` cites `<target>/.harness/docs/agents/WORKFLOW.md`;
  `sh harness-install.sh --self` leaves `git status` clean.
- **Sibling docs.** `git diff --numstat <base> -- docs/RATIONALE.md docs/SPEC-FORMAT.md
  docs/UMBRELLA.md docs/agents/INSTALL.md docs/agents/README.md AGENTS.md
  agents/orchestrator.md agents/fixer.md` prints added/deleted `4 4`, `1 1`, `1 1`, `1 1`, `2 1`,
  `3 2`, `2 2`, `1 1` (modified lines plus the one inserted index row and the one inserted
  reference row), and every changed line differs only in a path token or is that inserted row.
- **Mutation campaign.** Apply each row's mutant in isolation; every one reds its row; restore.
