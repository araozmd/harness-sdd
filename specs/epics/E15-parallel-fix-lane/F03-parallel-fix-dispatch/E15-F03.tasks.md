## Mandatory Reviewer behavioral gate
The Builder does not self-approve agent concurrency. Before an approve verdict,
the Reviewer shall execute the disposable-host scenarios in `E15-F03.tests.md`
for R7, R8, R9, R13, and R14 and write evidence to
`progress/E15-F03-review-round1/parallel-behavior.md` on the first review (using
the actual current round number after a rejection). The evidence must record
worker start/settle ordering, guarded non-overlap, the no-capability preflight's
zero-mutation snapshot (including delegate mode), sibling continuation after one
failure, and two distinct code PR identities with merge-observed traces. It must
also run the permanent real bookkeeping-PR/base-reconciliation/teardown fixture.
Any missing or failing scenario is a Reviewer rejection.
