# Derived waves and critical path — Tasks

> Atomic, sequential steps. The Builder works these top to bottom, one at a time. Tasks are
> **per-requirement red/green pairs** (ADR-0008): `T<n>a (R<n>)` writes the failing test named
> in `E36-F05.tests.md` and observes RED; `T<n>b (R<n>)` writes the minimal code (or prose) that
> turns it GREEN. **Each pair ends in a commit**, so a later weakening of that test is a diff
> the Reviewer can detect. There is no trailing "write tests" task.
> `tests/test_waves.sh` is discovered by `tools/run-tests.sh`'s `tests/test_*.sh` glob —
> no runner edit. Run single suites with `sh tests/test_waves.sh` while iterating and the
> full `sh tools/run-tests.sh` once, serially, before hand-off.
