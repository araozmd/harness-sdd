# Uncited plan rows block: plan-cite-check tool + Reviewer gate — Technical Plan

> Translates the .spec.md intent into design. Every table row cites the `R-id`(s) it serves
> or the `ADR-NNNN` that defers it (ADR-0009) — this plan must exit `0` under the tool it
> ships (R1 dogfood). Start high-level; don't over-specify internals that might be wrong. The
> Builder reads `progress/lessons.md` first; the lessons this plan leans on are named inline.

## Data model  (serves: R1, R2, R3, R4, R5, R7)

No stored state. The data model is the grammar the tool reads (copied, not paraphrased, from
`docs/SPEC-FORMAT.md` → *Plan rows cite an R-id or an ADR* and the F03 plan's *Data model*),
plus the readings this plan fixes where the grammar is silent.

| Entity | Form (byte-exact where quoted) | Tool reading where the grammar is silent | R-id |
|---|---|---|---|
| line | the plan read as UTF-8 (`encoding="utf-8"`, strict); every line's trailing `\r` then `\n` stripped before any rule; fenced code removed by `iter_unfenced()` (the fence.awk rule, see *Approach notes*) | invalid UTF-8 ⇒ exit 2 (R6), never a silent skip | R1, R6 |
| section | a heading line `^## (Data model\|API / interface\|Files to change\|Deferred)(\s\|$)` outside fences opens a **checked section**; it runs to the next line matching `^##? ` (a level-1 or level-2 heading) outside fences, or EOF; `###` lines stay inside | any other `## ` heading (`## CLI / interface`, `## DO NOT TOUCH`, `## Stack & dependencies`) is unchecked; the suffix after the heading name (`(serves: …)`, `(ADR-0009 — …)`) is ignored | R1, R2 |
| table row | a line matching `^\|` inside a checked section | a **table** is a maximal run of consecutive `^\|` lines; its **separator row** is a `^\|` line whose cells (split on unescaped `\|`) are each empty or match `^:?-+:?$`; the **header row** is the row immediately before a separator row; every other `^\|` line in the run is a **data row**; a run with no separator has no header — all its rows are data rows | R2 |
| citation tokens | `R[0-9]+` and `ADR-[0-9]{4}` searched over the whole data row (any cell) after stripping `*`, `` ` ``, `"`, `'`; a row with neither ⇒ `uncited-row <plan>:<line> <heading>` (`<heading>` = the matched name, one of the four, no suffix) | the `R` token starts at a non-alphanumeric boundary: `(?<![A-Za-z0-9])R[0-9]+` — so `PR304`, `CR12` are not citations; `R-id` (no digits) is not a token; a range `R1–R12` yields `R1` and `R12`, not expanded (as `tasks-pair-check`) | R2, R3 |
| spec R-id | `^[ \t]*-[ \t]+\*\*(R[0-9]+)(?:\*\*\|[ \t]+(?:—\|–\|-))` outside fences in the `--spec` file, first-appearance order, repeated id counts once (the `tasks-pair-check` `RID_RE`, copied) | zero ids ⇒ exit 2; a row `R<n>` not in the set ⇒ `unknown-rid <plan>:<line> R<n>`; without `--spec` the check is skipped and the `ok` line carries `spec: not checked` | R3, R6 |
| ADR namespace | every directory literally named `adr` under `--specs-dir` (default: nearest ancestor of `os.path.realpath(plan)` whose basename is `specs`; none ⇒ exit 2); token = parent basename, `platform` for `<specs-dir>/adr`; index = for each `*.md` **directly** in it (regular files only, `adr/archive/` is not a namespace), the leading `[0-9]+` of the basename, tagged `<token>/<NNNN>` | a specs dir with no `adr/` at all yields an empty index: any ADR citation is then `unresolved-adr` (there is nothing to cite) | R4, R6 |
| ADR citation | in a data row, `([A-Za-z0-9_-]+)?([ /])?ADR-([0-9]{4})` after wrapper stripping and after appending `\|` to each `ADR-NNNN` (so one citation cannot eat the previous one — 2c's trick); qualifier with `/` ⇒ **qualified** (unknown token ⇒ `unresolved-adr … unknown-namespace`); qualifier with a space ⇒ qualified only when the token is a known namespace, else **bare**; qualified resolves in that namespace only, bare in any | reason words: `not-in-namespace <ns>`, `unknown-namespace <ns>`, `not-in-any-namespace` | R4 |
| `## Deferred` | section present (else `deferred-section-missing <plan>`); **table form** = a header row whose trimmed cells are exactly `Bolt-on`, `Deferred by`, `Trigger`; **none form** = a line matching `^Deferred: none — \S` (em dash U+2014, then a non-empty why); counts: table and ≥1 none line ⇒ `deferred-form <plan> both`; neither ⇒ `deferred-form <plan> neither`; ≥2 none lines ⇒ `deferred-form <plan> <n>-none-lines`; table with no data row ⇒ `deferred-table-empty <plan>:<line>`; data row whose **second** cell has no `ADR-[0-9]{4}` ⇒ `deferred-row-no-adr <plan>:<line>`; a cited ADR that resolves but whose file has no line matching `^- \*\*Status:\*\* deferred` ⇒ `deferred-by-not-deferred <plan>:<line> <cite> <adr-path>`; resolves, is deferred, but no line matching `^- \*\*Trigger:\*\* \S` ⇒ `deferred-adr-no-trigger <plan>:<line> <cite> <adr-path>` | prose lines beside the none line are fine (F03's plan has a `Stage:` line there); a Bolt-on data row is **also** a data row under a checked heading, so `uncited-row` cannot fire on it when its second cell cites (the ADR token satisfies both); the row rule's `unresolved-adr` fires on an unresolvable Deferred-by cite and the deferred-specific codes fire only when it resolved | R5 |
| sweep finding | `--sweep <specs-dir>`: for each ADR file in the index, `^- \*\*Status:\*\* deferred` present and no `^- \*\*Trigger:\*\* \S` ⇒ `deferred-no-trigger <path>`; `<specs-dir>/product.md` first `---` … `---` block (line 1 must be `---`; block ends at the next `^---$`): a line `^stage:` not matching `^stage: (discovery\|pilot\|production)$` ⇒ `stage-unrecognized <path>:<line> <text>` | absent `product.md`, no frontmatter, or no `stage:` line ⇒ no finding; an unreadable `<specs-dir>` ⇒ exit 2 | R7 |
| grandfather verdict | `--grandfathered <plan> [--base <ref>]`: tool merge = committer time of the first `--first-parent --reverse` commit on `<base>` touching `tools/plan-cite-check.py` or `.harness/tools/plan-cite-check.py`; plan date = min author time of `git log --diff-filter=A HEAD -- <rel>`; `flag` when the tool is not on `<base>` or plan < merge; else `reject` (including no commit); `<base>` = `--base`, else `refs/remotes/origin/HEAD`, else the first of `origin/main main origin/master master origin/trunk trunk` that resolves | exit 2 when the path is not in a git work tree, `--base` does not resolve, or no base resolves (message names the fallbacks and `--base`) | R8 |

**Decision — the tool reads files, not the board.** Lint and grandfather modes are pure
functions of paths given on `argv`; only `init.sh` reads `state/tasks.json` to choose which
plans to sweep (mirroring 2c/2b: the board is read, never written). **Decision — a second
copy of `iter_unfenced()` and of the grandfather algorithm**, not an import from
`tasks-pair-check.py`: the installer copies `tools/` wholesale, but a tool that imports its
sibling breaks when either is moved, pinned or removed, and the spec forbids coupling beyond
what this plan names. Both copies are parity-tested (fence: R11 corpus; grandfather: R8 fixture
repo). **Decision — `deferred-by-not-deferred` / `deferred-adr-no-trigger` are row violations**,
not sweep findings: form 4 says the *Trigger* cell copies the ADR's `Trigger:` text, so a
`## Deferred` row citing a non-deferred or trigger-less ADR is the plan's defect at the point
of citation; the sweep catches the same ADR defect for ADRs nobody cites yet.

## Approach notes

**Sequencing.** Walking skeleton first: R1 (the tool exits `0` with an `ok` line on the
positive fixture, including CRLF and fenced decoys) is the one behavior observable at the

**Section bounds.** Build the unfenced line list with original line numbers first
(`[(lineno, text)]`), then scan: a `^##? ` line closes the open section; a line matching the

blank or prose line ends the run. Cell split: `re.split(r'(?<!\\)\|', line)`, drop the empty
first/last cells produced by the leading/trailing pipe, `strip()` each. Header detection is
by **position before a separator**, never by text — the template's Data-model header has no

**Namespaces.** `discover_namespaces(specs_dir)` walks `os.walk(specs_dir)` for directories

`**platform** ADR-0001` is therefore qualified; a prose word such as `the ADR-0001` is bare.
