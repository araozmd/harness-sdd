# Uncited plan rows block: plan-cite-check tool + Reviewer gate — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test,
> and every row names the mutant that kills it. The Reviewer fails the feature if any R-id
> lacks a passing test, or if a named mutant survives.
>
> **Suite.** A new POSIX `sh` suite, `tests/test_plan_cite.sh` (PC), `set -eu`, `LC_ALL=C`,
> `fail`/`pass`, run by `tools/run-tests.sh` under the strictest shell it can probe (dash on
> CI) — assert `rc -eq N`, never a shell-dependent code; capture with `set +e; …; rc=$?;
> set -e`. `TOOL="$ROOT/tools/plan-cite-check.py"`; `FX="$ROOT/tests/fixtures/plan-cite"`;
> each behavioral row copies the fixture tree into its own `$T/<row>/specs` (`cp -R`) and
> derives its variant with `sed`/`printf` so every row has exactly one cause. Prose rows run
> **one fresh install** (`CODEX_HOME="$T/ch" HOME="$T/home" sh "$ROOT/harness-install.sh"
> --agents=claude "$T/tgt"`, `I="$T/tgt/.harness"`) and grep the **installed** copy inside a
> **bounded slice**: `## What you check` is extracted fence-aware with `tests/lib/fence.awk`
> (the house awk heading extractor is fence-blind — lesson), the Stage/grammar sections by
> heading line numbers (`lineno`/`span` as `tests/test_stage_nfrs.sh` does). Co-occurrence
> anchors fold newlines (`tr '\n' ' ' | tr -s ' ' | grep -qE 'A[^.]{0,N}B'`) and anchor whole
> sentences; every positive anchor on a flipped sentence is paired with a negative
> `! grep -qF 'not yet enforced'` on the same slice. The suite never reads `VERSION` as a
> literal, never diffs a DO-NOT-TOUCH file against `main` (`cksum` instead), never writes
> `state/` or a live spec. Installer behavior (R11) lives in `tests/test_install.sh`.
>
> **Markdown escaping.** Table cells below escape `|` as `\|` for markdown only; the literal
> strings are `| Entity | Field | Type | Notes | R-id |` and `| Bolt-on | Deferred by |
> Trigger |` with bare pipes.
>
> **Pre-change RED (Builder obligation).** Confirm each prose anchor RED on the pre-change
> blob (install from a `git stash`-ed tree into a second temp dir) before trusting it, and
> record the check in `progress/E36-F04/builder.md` — lesson 2026-09-06.

## Behavioral / end-to-end checks (Reviewer)

- Run `python3 tools/plan-cite-check.py` on this feature's plan with `--spec`: exit 0, one
  `ok` line. Append an uncited row to its `## Files to change` in a scratch copy: exit 1,
  one `uncited-row` line naming the line number, then `FAIL 1 violation(s)`.
- Run it on the sibling in-flight plans fetched read-only
  (`git show feat/E36-F02-observable-slices:specs/epics/E36-emergent-slices/F02-observable-slices/E36-F02.plan.md > /tmp/…`
  and the F07 one): both report `deferred-section-missing` (no `## Deferred`) — exactly the
  ambush case; then `--grandfathered` on the branch-checked-out file flags them once this
  tool is on `main` (their first-add author time precedes the merge). While the tool is not
  on `main`, every plan is flagged.
- `./init.sh` from the worktree root: a new `✅ plan citations …` line (this repo has no
  `spec-ready`/`in-progress`/`in-review` feature whose plan fails) and the gate still passes;
  plant a `deferred` ADR without `Trigger:` in a scratch copy of the repo ⇒ one `⚠️
  plan-cite: deferred-no-trigger` line, exit still 0.
- `python3 tools/plan-cite-check.py --sweep specs` on this repo: `ok sweep 10 ADR(s), stage:
  production`.
- Fresh install into a temp target (`CODEX_HOME`/`HOME` sandboxed): the tool is executable
  under `.harness/tools/`, the installed Reviewer carries item 8, the installed doc-critic
  carries the new section, the installed plan template's Data-model header has `R-id`.
- Mutate (3b): delete `iter_unfenced()`'s tilde clause ⇒ `R11_fence_parity` red; delete
  Reviewer item 8 ⇒ `R9_reviewer_check8` red; restore from `.mutbak`, confirm with `diff`.
- `sh harness-install.sh --self` leaves `git status --short` empty of generated-glue paths;
  `cksum` of every DO-NOT-TOUCH file recorded at T0 equals the value after T12b.
