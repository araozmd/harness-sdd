# Fix — Repoint harness-sdd URL defaults to araozmd/harness-loop

## Problem / who
The GitHub repo was renamed from araozmd/harness-sdd to araozmd/harness-loop on 2026-11-12.
GitHub redirects the old URL, so nothing is broken today. Two shipped defaults still name
the old repo, though, and work only as long as the redirect holds. The redirect breaks
permanently if anyone ever creates a repo at the old name.
- The E38 update check's default remote: `tools/harness-update.sh:62`, plus the
  `update.remote` comment in `harness.config.yaml:370` and its byte-identical installer
  heredoc at `harness-install.sh:524`.
- The feedback reporter's default repo: `tools/harness-report.sh:91`
  `DEFAULT_REPO`, plus the `feedback.repo` seed in `harness.config.yaml:446` and
  `harness-install.sh:652`.
Prose that tells agents how to parse a repo slug also uses the old name as its example:
`agents/orchestrator.md:94` and the generated triage glue.

## Intended fix
- Change the two defaults, the seed lines and their comments to `araozmd/harness-loop`.
- **Existing installs:** `feedback.repo` is seeded once into each consumer's
  `harness.config.yaml` and is project-owned. Have `migrate_config` rewrite the value
  ONLY when it is byte-identical to the old shipped default
  `github.com/araozmd/harness-sdd`, and leave any customized value alone. Apply the same
  rule to an `update.remote` that equals the old default URL, if the update block seeds
  one. Report each rewrite in one info line.
- `agents/orchestrator.md:94` example slug: replace it, then regenerate the glue with
  `sh harness-install.sh --self`. Never hand-edit `.claude/`, `.opencode/` or `.agents/`.
- `docs/INSTALL.md:560` and `docs/agents/README.md:425`: replace the example value. That
  text moved verbatim in E39-F01; a value-only update is fine here.
- Tests: update `tests/test_feedback_config.sh` and `tests/test_feedback_report.sh` to
  the new default, and update the update-check default if a test pins it. Add pins for the
  migration rule:
  - the old default gets rewritten;
  - a custom value is untouched;
  - an already-new value is untouched.
  Each pin must fail without the fix.
- Leave historical references (`araozmd/harness-sdd#141`, `#96` and similar PR citations
  in comments and prose) unchanged. They are history, and GitHub redirects them.
- Already done by the Orchestrator, commit as-is: `assets/social-preview.png` and
  `assets/src/social-preview.html` with the new tagline.
- Bump VERSION as PATCH, 0.110.0 → 0.110.1 (🐛), with a CHANGELOG entry.
