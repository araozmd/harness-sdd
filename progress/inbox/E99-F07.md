# Change-size measurement: remaining path / symlink / coverage gaps

## Why this exists
PR #78 reached three consecutive review rounds with **zero blocking findings**, so it merged
under `blocking_severities: "P0,P1"`. Four non-blocking findings were deliberately deferred
here rather than starting a fourth fix cycle — the stopping rule was stated before the round,
not discovered after it. All four are real; each is reproducible.

## The four items

**1. `git diff --numstat` C-quotes TRACKED paths too (P2, `tools/change-size.sh`).**
The untracked side was moved to `ls-files -z` during review, but the tracked side still parses
plain `--numstat`. `core.quotePath=false` does not stop git C-quoting a tracked path containing
`"`, a backslash or a tab, so the classifier sees `"src/foo\".spec.js"` — whose trailing quote
defeats the built-in `[._-](test|spec)\.[a-z]+$` suffix rule, charging a test file to the
production budget. Same defect class as the untracked one, same fix: `--numstat -z`.
*This is the highest-value item: it silently overstates production lines.*

**2. Untracked symlinks are followed (P2, `tools/change-size.sh`).**
`awk END{print NR}` reads through a symlink and counts the target's lines; git records a
symlink as a one-line link value. A link to a 2,000-line file therefore contributes 2,000 lines
before commit and 1 after — reintroducing exactly the commit-coupling that R5b exists to
remove. Broken links and links to directories are skipped entirely by the preceding `[ -f ]`.

**3. The pre-PR handoff only fires in parallel-fix mode (P2, `agents/orchestrator.md`).**
The instruction sits inside the fenced *Targeted parallel-fix worker mode*, so it runs only for
`/sdd-fix-parallel` E99 workers. Ordinary features routed through the main `in-review` flow —
and umbrella child PRs — never reach it, so the Orchestrator never carries the tier into those
PR bodies as E21-F02 requires. **This is a coverage hole in the feature as shipped**, not a
robustness nit: the check is correct and simply is not invoked on the common path.

**4. `--cache` paths containing whitespace (P3, `tools/pr-round-trend.sh`).**
`_readable` concatenates filenames and is expanded unquoted, so `cat` splits a whitespace-
containing cache path into several arguments. The verdict still computes, but the aggregation
fails under `|| true` and `top_files` comes back empty — losing the seam list on exactly the
non-converging handoff that exists to carry it.

## Constraints
- `tools/change-size.sh` and `tools/pr-round-trend.sh` are harness-owned; changes must keep
  `sh -n` and `dash -n` clean, since both are asserted POSIX.
- Do not weaken the guarantees already tested in `tests/test_change_size.sh`
  (R1b escapes, R3b binaries, R5b uncommitted, R5c default branch, R7b whitespace regexes,
  R7c unterminated lines, R7d C-quoted untracked, R8b phantom record, R8c JSON escaping).
- Item 3 touches `agents/orchestrator.md`'s main routing table — check the Reviewer's
  cross-file consistency rule before moving the instruction, and keep `agents/reviewer.md`'s
  copy of the handoff in agreement.
- Do not freeze an exact VERSION or diff DO-NOT-TOUCH files against `main` in any added test.

## Not in scope
- A filename containing a literal NEWLINE. Documented inline as unsupported; `-z` framing
  handles every other special character.
