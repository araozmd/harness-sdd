# Intent — Driller observable-slice rule and walking skeleton; doc-critic checks both

## Problem / who
The Driller (agents/driller.md) is the only role that decides a feature's size and shape,
and its only rule is the `max_requirements` count. A decomposition "F01 data model, F02 API,
F03 UI" is legal and is the LLM default. The result is features nobody can exercise until
the last one lands. ADR-0008 decision 1 names the shape rule; this feature installs it where
decomposition happens and gives the doc-critic a checkable property.

## Success outcome
- `agents/driller.md` carries an "Observable slice" rule beside the size budget: every
  seeded feature's brief names at least one behavior observable at the product boundary
  (HTTP/CLI/UI/file/exit code), the first feature of a fresh epic is the walking skeleton
  (thinnest end-to-end exercisable path), and a candidate whose outcome is only internal is
  merged into the slice that consumes it. The decision is recorded in `epic.md` Notes the
  same way size splits are (advisory, never blocks, but always recorded), as one line
  beginning `Observable-slice exemption:` so the doc-critic can find it mechanically.
- `specs/_templates/inbox-brief.md` gains an `## Observable behavior` section (one line:
  surface + what a user/client sees). Inception fills it too (agents/inception.md).
- `agents/doc-critic.md` `target-type=epic-decomposition` flags: a feature brief with an
  empty/absent Observable behavior section; a first feature that is not end-to-end; a brief
  whose success outcome names only internal artifacts. Advisory, like its other findings.
- Tests assert the rule tokens in driller/doc-critic prose, the template section, and that
  `tests/test_doc_critic.sh`-style fixtures exercise the three findings.

## Scope / boundaries
In scope: `agents/driller.md`, `agents/doc-critic.md`, `agents/inception.md`,
`specs/_templates/inbox-brief.md`, `.claude/commands/sdd-drill.md` via its emitter (regenerate
with `--self`; never hand-edit generated files), docs, tests. Out of scope: Architect task
ordering (E36-F01); any change to `max_requirements` semantics; Planner epic sketches.

## Chosen options
- Shape rule is advisory-but-recorded, mirroring the E21-F01 size rule, so it never blocks
  a legitimately internal epic (e.g. a pure library) — the Driller writes one line saying why.

## Constraints
- Honor ADR-0008. Every generated command surface regenerated via `sh harness-install.sh
  --self` and asserted in `tests/test_install.sh` when its text changes.
- Doc-critic stays advisory (RATIONALE C5).

## Open questions
