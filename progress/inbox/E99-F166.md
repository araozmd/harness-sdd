# Intent — R9d fence-convention scan is blind after a stray apostrophe

## Problem / who
`tests/test_change_size.sh` R9d (around lines 954-977) finds awk programs with
`re.finditer(r"'([^']*)'", src)`, which pairs single quotes across the whole file. One
apostrophe in a shell comment or string shifts every pairing after it, so later awk
programs are never scanned and R9d passes without checking them. The E32-F01 Reviewer
showed this: mutant M17 removed `fence_delim($0)` from `_section` in
`tests/test_feedback_config.sh` and R9d stayed green.

## Success outcome
R9d finds every awk program in the files it scans, whatever apostrophes appear before it.
A regression test puts a stray apostrophe ahead of a non-fence-aware awk program and
fails.

## Constraints
- Test-suite change only; no installed-body change and no VERSION bump.
- After it lands, update the caveat comment at `tests/test_feedback_config.sh` (around
  line 354) that points to this fix.
