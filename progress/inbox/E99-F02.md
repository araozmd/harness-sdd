# Intent — Validate cited ADR-NNNN ids resolve to specs/adr/ files

## Problem / who
Nothing in the harness validates that an `ADR-NNNN` id cited in a feature spec's
`## Architecture alignment` section actually resolves to an existing
`specs/adr/NNNN-*.md` file. The Reviewer's ADR-citation check
(`agents/reviewer.md` → "ADR-citation check") only verifies the section exists and
cites ≥1 id (or states `ADRs touched: none`) — a Driller/Architect typo
(e.g. `ADR-0012` when only `0002` exists) propagates silently into approved specs,
breaking the design-to-feature traceability the section exists to provide. Serves
anyone relying on architecture alignment (Architect, Reviewer, humans auditing specs).

## Success outcome
- Reviewer's ADR-citation check additionally verifies each cited `ADR-NNNN` id
  resolves to an existing `specs/adr/NNNN-*.md` file; a cited-but-nonexistent id is
  a **soft flag** (same "suspected but not provably violated → flag, don't block"
  verdict rule as the existing check — the ADR may have been renamed/removed
  legitimately).
- `init.sh` gains a **warn-only** sweep: scan feature `.spec.md` files'
  `## Architecture alignment` sections for `ADR-NNNN` citations and warn (never
  fail) on ids with no matching `specs/adr/NNNN-*.md`. Catches typos at session
  start, before review time.
- ≥1 test covering the new behavior (fixture spec citing a nonexistent ADR id →
  init.sh warns; existing-valid citation → silent).

## Scope / boundaries
- IN: `agents/reviewer.md` (extend ADR-citation check), `init.sh` (warn-only
  sweep), a test (wired into the existing suite per `verification.test_command`
  conventions — see tests/README or sibling test files).
- OUT: no hard reject / no non-zero exit for a missing ADR (soft flag / warn
  only); no changes to Architect/Driller contracts; no schema changes; no
  installer-generated command changes (but if init.sh changes ship in the
  installed body, VERSION bump rules apply per AGENTS.md).

## Chosen options
- Both layers (Reviewer soft flag + init.sh warn-only sweep), not Reviewer-only —
  the sweep is cheap, zero-dep, and catches the typo earliest.
- Warn-only in init.sh (never gate the environment on a doc-level citation issue).

## Constraints
- init.sh sweep must stay zero-dependency (POSIX/bash + standard tools), warn-only,
  and must not fire in repos with no `specs/adr/` (graceful degradation, mirroring
  the existing ADR-citation check preconditions).
- Follow the permanent-suite test anti-pattern rule: tests must not freeze exact
  VERSION or diff harness body files against main.

## Open questions
- Exact citation-extraction regex (only ids inside the `## Architecture alignment`
  section should count, not incidental `ADR-NNNN` mentions elsewhere) — Builder's
  judgment.
