# Intent — Keep reviewer mutation checks off shared tracked files

## Problem / who
Issue #222 documents parallel reviewers editing one shared umbrella `.gitignore` during mutation checks, corrupting one another's measurements. Backup and restore preserve a file after the fact but do not protect concurrent readers.

## Intended fix
Require mutations of shared tracked files to run in a private worktree or disposable repository; use named assertions from that fixture and restore between mutants. Preserve safe revert for private files and existing `*.mutbak` visibility. Follow `progress/issue-triage/approved-design.md` and `plan-222.md`.

## How to verify
Add a focused check 3b contract test that fails when the new prohibition or private-fixture requirement is removed or inverted. Prove its force with mutations in a private worktree. Run the focused reviewer tests, `./init.sh`, and configured verification. Obtain independent Reviewer approval before a PR.
