# E23-F01 review round 3

The four original quality findings and the partial-unit spec gap are closed. One
Important ownership issue remains: last-written checks follow symlinks.

`test -f`, `cmp`, and shell redirection follow symlinked files and directories. A
symlinked skill unit or role path whose external target matches the recorded stamp can
therefore be accepted as harness-owned and overwritten later when generated bytes or
model routing change.

Required fix:

- reject symlinked destination files and every writable path component under
  `.agents/skills/<command>/` and `.codex/agents/` before ownership checks, stamping,
  generation, reclamation, or writes;
- preserve the link and its external target unchanged;
- do not create an ownership stamp for a rejected symlinked artifact/unit;
- add regressions for symlinked skill units/files and role files/directories, then
  change generated bytes or model routing and prove external targets stay byte-identical;
- retain all previously green ownership, explicit-only, migration, and non-Codex tests.
