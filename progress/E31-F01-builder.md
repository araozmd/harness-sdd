## Deviations from the task text (all deliberate, all reported)

1. **Two existing tests encoded the old destructive behavior and had to be updated.**
   `tests/test_install.sh`'s `claude,codex → claude,opencode` reconcile block asserted a
   codex-removal warning that was only ever produced by reclaiming the **shared** skills. With
   the corrected shared-claimant rule those skills survive (OpenCode claims them), so the block
   now asserts survival (R2) and the R13 warning is covered in the new R3 test's last-claimant
   deselect. `tests/test_pr_loop.sh` R4 asserted the shared `sdd-pr-loop` skill is reclaimed when
   codex is deselected while `--agents=opencode`; under the feature that unit is claimed by
   OpenCode and must survive. Both updates strengthen, not weaken, the assertions. The tasks'
   file list did not name `test_pr_loop.sh`; the change was unavoidable.
2. **The `codex)` reclaim branch had to be gated, not only `skill_unit_claimed()` widened.**
   T2 authorises extending a prior-selection check that excludes opencode. Leaving the branch
   unconditional makes `codex,opencode → deselect codex` reclaim units OpenCode still reads —
   the exact silent-destructive class ADR-0003 warns about. The one predicate is used at both
   branches; no second inline `agent_selected` condition was added.
3. **The frozen golden fixture needed no refresh — the task/revalidation premise is wrong.**
   `tests/test_codex_native.sh:189` byte-compares `.claude/agents/*.md`, `.claude/commands/*.md`,
   `.opencode/command/*.md`, `.opencode/agent/*.md`, `opencode.json` — it does **not** glob
   `.agents/skills`. That exclusion is correct: F01 intentionally changes those bytes and the
   fixture is frozen v0.78.1 output under `SHA256SUMS`; adding skills to the golden (or editing
   the fixture) would falsify the snapshot, which `progress/lessons.md` forbids. The R4 adapter
   coverage was added directly in that suite instead. No comparison was weakened.
4. **Source glue regenerated.** `sh harness-install.sh --self` rewrote the seven committed
   `.agents/skills/*/SKILL.md` and `.claude/.glue-manifest`; `test_self_drift.sh` requires the
   committed copy to match the regenerated copy. No `.opencode/*` or `opencode.json` was touched
   (that remains F02). `self_install` itself was not modified.
5. **VERSION / CHANGELOG not bumped.** T1–T12 do not ask for a release bump, and
   `test_codex_native.sh` currently pins the current VERSION literal (`0.80.0`), so a bump would
   need that literal synced in the same change. Flagged for the Orchestrator's release decision.
