# harness-loop — brand

![harness-loop](https://raw.githubusercontent.com/araozmd/harness-loop/main/assets/logo-wordmark.svg)

**Name.** harness-loop

**Tagline.** Autonomous agents, safely: every change is independently reviewed before it merges.

Installed names do not change: `.harness/`, `harness-install.sh`, `harness.config.yaml` and the `/sdd-*` commands keep their names.

The logo files live in the repository `assets/` directory, which is not installed. The images on this page load from the canonical repository by absolute URL, so they show once the files are on `main`; the file names below are code spans.

## Positioning

Fast and safe. Autonomous agents move quickly. harness-loop makes that speed safe: every change is independently reviewed before it merges, and the default path adds a spec and a human gate.

Claim only what the process does: independent review of every change. Do not quote speed numbers or promise a human gate on every task.

## Voice

Write the way the docs are written. Be plain, short and direct. Say what a thing does. Use one idea per paragraph and imperative steps. Leave out filler, hedging and history.

## Logo

![Every logo variant on its background](https://raw.githubusercontent.com/araozmd/harness-loop/main/assets/brand-sheet.png)

The mark is a triangle drawn as a loop: three nodes joined by arcs, one arc in coral. The wordmark sets `harness-loop` beside the mark (horizontal) or under it (stacked). Pick the variant by the background it sits on.

| Variant | Files | Use it on | Do not |
|---|---|---|---|
| Light | `assets/logo.svg`, `assets/logo-wordmark.svg`, `assets/logo-wordmark-stacked.svg` | white and light backgrounds | put it on dark or busy backgrounds |
| Dark | `assets/logo-dark.svg`, `assets/logo-wordmark-dark.svg`, `assets/logo-wordmark-stacked-dark.svg` | dark UI such as GitHub dark mode | use it on white |
| Reversed | `assets/logo-reversed.svg`, `assets/logo-wordmark-reversed.svg`, `assets/logo-wordmark-stacked-reversed.svg` | solid indigo `#1D0658` | use it on any other colour |
| Mono black | `assets/logo-mono-black.svg`, `assets/logo-wordmark-mono-black.svg`, `assets/logo-wordmark-stacked-mono-black.svg` | white backgrounds in one-colour print or stamps | use it on a tint or a photo; its cutouts are solid, not transparent |
| Mono white | `assets/logo-mono-white.svg`, `assets/logo-wordmark-mono-white.svg`, `assets/logo-wordmark-stacked-mono-white.svg` | black backgrounds | use it on a tint or a photo; its cutouts are solid, not transparent |

Other files:

- `assets/favicon.svg` is the browser icon. It switches to its dark colours by itself.
- `assets/png/` holds raster exports for places that cannot show SVG: `@2x` wordmarks, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` (180 px) and `icon-512.png`.
- `assets/social-preview.png` (1280×640) is the GitHub social preview. Upload it in the repository settings.
- `assets/hero.svg` is the wide illustration for landing pages.
- `assets/brand-sheet.png` shows every variant on its background.
- `assets/src/` holds the HTML sources used to regenerate the sheet and the preview.

Rules for every variant:

- Use the files as they are. Do not recolour, stretch, rotate or outline them.
- Do not add text to the mark or place it inside a shape.
- Do not pair it with mascot imagery.
